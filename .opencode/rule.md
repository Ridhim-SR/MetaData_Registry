# Project Rules

## Progress Tracking

**MANDATORY**: Update progress.md at repository root whenever:
1. Work is committed (any git commit)
2. Work is completed (feature done, task finished)
3. User says I am done for the day / wrap up / similar

### What to Update in progress.md
- Status (In Progress / Complete / Blocked)
- New tables/files added
- Commands executed
- OpenMetadata entities published
- Future work items (add/remove checkboxes)
- Branch name if changed

### Enforcement
- This rule applies to ALL sessions
- Check progress.md at start of each session
- Update before any commit or session end
